Stratagem Trainer 1.0.0 — macOS

configs/ and lang/ contain editable JSON source files. Runtime copies are bundled in the executable. Import changed configs in the app, or rebuild to replace bundled defaults.
web/ is the offline-capable web version; serve it over HTTP(S), rather than opening index.html as a local file.
Native artifacts are generated by GitHub Actions on the corresponding operating system.
macOS builds are unsigned until a developer identity is configured. Gatekeeper may require manual approval in Privacy & Security.
