# Working on Stratagem Trainer

- Human instructions override this file. Keep changes concrete and autonomous within the requested scope.
- Create a GitHub issue for each meaningful step before implementation. Link commits to the issue; use `Closes #N` only after its acceptance criteria pass. Leave externally blocked work open.
- Canonical app sources are in `shared/sourcecode`; config/lang assets in `shared/application`. Platform `sourcecode` snapshots are generated by `scripts/stage-platforms.mjs`; do not edit duplicated snapshots.
- New Warbonds require verified names, release dates and actual call-in sequences with source URLs. Empty Warbonds are valid. Never invent codes.
- Every UI string must exist in every language JSON. Existing game item names may retain their canonical English name.
- Validate downloaded/imported data through `parsePack`/`validatePack`. Keep Electron sandboxing, context isolation and HTTPS/size/time limits.
- Run `pnpm check`, `pnpm test`, `node --test desktop/https-download.test.cjs` and relevant Playwright scenarios for functional changes. Build before native sync/staging.
- Do not commit secrets, keystores, provisioning profiles, private certificates, personal backups, generated build caches or native binaries to Git. Release binaries belong in GitHub Releases.
- Native iPhone installation requires valid Apple signing. An unsigned IPA is a developer artifact; do not present it as directly installable. The PWA is usable without Apple credentials.
